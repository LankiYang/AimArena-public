# AimArena · 源码审查版

本仓库收录部分客户端、服务端和共享模块，供阅读与审查。它不是完整游戏，也不是可部署的发行包：部分依赖、构建配置及地图、角色、武器、音频等素材未包含，不能直接启动完整对局。

公开内容不包含私有仓库历史、证书、部署配置或生产数据。未通过公开范围核查的代码和素材不在本仓库中；对剩余内容的权利和安全性仍需进一步核查。

## 可独立验证的规则模块

经典生化模式的阶段、感染与胜负规则作为独立模块保留在 `game/server/infection.ts` 和 `game/shared/infection.ts`。为使该模块独立运行，审查版将固定 tick 频率和队伍类型直接定义在共享规则文件中；该适配不改变规则数值。

使用支持原生 TypeScript 类型剥离的 Node.js 22.18 或更新版本：

```sh
node game/tools/infection-check.mjs
```

该检查覆盖准备期、母体选择、感染、中途加入、离开和双方胜负。其余文件为摘选源码，依赖不完整，不能据此推断完整游戏可构建或运行。
